Bytescript

A small, object-oriented, embeddable programming language with its own bytecode VM — written in C, now running on Windows, Linux and macOS.

func Number fib(Number n)
    if n <= 1 then return n end

    Number a = 0
    Number b = 1

    for i = 1, n repeat
        Number tmp = a + b
        a = b
        b = tmp
    end

    return b
end

print(fib(10))
55

…and it is quick: the bundled benchmark measures fib(500) at a few microseconds per call (bytecode VM with NaN-boxed values).

class Counter
    func static Counter __new()
        Number self.value = 0
        return self
    end

    func increment()
        self.value = self.value + 1
    end

    func Number get()
        return self.value
    end
end

Counter clicks = Counter:new()
clicks:increment()
clicks:increment()
print(clicks:get())
2

What you get

🧩

Object-oriented

Classes, constructors (__new), methods, static methods and operator overloading through dunder methods like __concat.

🏷️

Optional types

Annotate variables, arguments and return values (Number, String, Table, your own classes…) or use var and let it flow. Types are checked before your code runs.

🗂️

One mighty Table

Tables are both arrays and hash maps, with slicing, filling, copying, iteration and more built in.

⚙️

Bytecode VM

Your code compiles to bytecode for a register-based VM. Every value is a NaN-boxed 64-bit word, so numbers never allocate.

🔌

Embeddable in C

Link bytescript.lib / libbytescript, include bytescript.h, run scripts or write your own C modules — that's how the whole standard library is made.

🖥️

Cross-platform new in 1.1

Builds and runs on Windows, Linux and macOS from the same sources. Old code importing "Time.dll" keeps working everywhere.

Quick start

Get Bytescript

Download a build, or compile it yourself (GCC + make, two minutes):

git clone https://github.com/gefrus112/Bytescript.git
cd Bytescript
make

Full step-by-step install guide →

Write a program

Save this as hello.bs:

String who = "world"
print("Hello, " .. who .. "!")

Run it

bytescript hello.bs
bytescript -e "print(6 * 7)"   -- run a snippet
bytescript                      -- interactive REPL

Then explore the documentation and the bundled exemples/ programs.

Standard library

Batteries included — built-ins are always available, library modules are imported by name:

Built-ins

print, input, exec… plus rich Table, String, IO/File and Error classes.

Math

sqrt, sin/cos/tan, floor, clamp, constants pi, e, inf and friends.

OS & Time

Environment, paths, working directory, running commands; wall clock, high-precision clock and sleep.

Json

Parse, stringify, validate and load/save JSON files as Bytescript tables.

Random & Base64

Seeded random numbers and ranges; Base64 encode/decode.

Debug

Assertions with proper AssertionErrors, plus a bytecode disassembler.

New in 1.1

  • Linux & macOS support — full port of the interpreter and every C stdlib module.
  • New CLI — --help, --version, -e "code" and an interactive REPL that survives errors.
  • Real bug fixes — !=, variable < comparisons, unary -/not and method calls on literals used to crash or miscompute; there's a test suite (make test) guarding them now.
  • This website, a VS Code syntax-highlighting extension, and CI builds for all three OSes.
