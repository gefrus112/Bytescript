How to install Bytescript

There are two ways to get Bytescript: download a ready-made build (easiest) or compile it from source (about two minutes, works everywhere). Pick your operating system — we tried to guess it for you.

However you install it, one rule matters: keep the whole dist/ folder together. The interpreter finds its standard library in the stdlib/ folder sitting next to the executable.

Windows

Option A — download a release (recommended)

Download

Grab the latest Windows build from the download page (a .zip containing a dist folder with bytescript.exe, bytescript.dll and stdlib/).

Unzip somewhere permanent

For example C:\Program Files\Bytescript\. You should end up with:

C:\Program Files\Bytescript\
├── bytescript.exe
├── bytescript.dll / bytescript.lib
├── bytescript.h / bytev.h
└── stdlib\   (Math, Time, OS... modules)

Add it to your PATH

  1. Press Win and search "Edit the system environment variables", open it.
  2. Click Environment Variables…
  3. Under User variables (or System variables), select Path → Edit → New and paste C:\Program Files\Bytescript.
  4. OK every dialog, then open a new terminal.

Check it works

bytescript --version
bytescript -e "print(2 + 3)"

You should see Bytescript 1.1.0 and 5.

Option B — build from source

Install a C compiler

Install MSYS2, open the MSYS2 MinGW 64-bit terminal and run:

pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-make

Get the source and build

git clone https://github.com/gefrus112/Bytescript.git
cd Bytescript
mingw32-make

This produces the dist/ folder — the same layout as the release download.

Run the tests (optional but wise)

./tests/run_tests.sh

All 24 checks should pass.

Install it

Move the dist/ folder's contents to C:\Program Files\Bytescript\ and add that folder to your Path (Option A, step 3).

Linux

Build from source (recommended — it's quick)

Install build tools

# Debian / Ubuntu
sudo apt install build-essential git

# Fedora
sudo dnf install gcc make git

# Arch
sudo pacman -S base-devel git

Clone and build

git clone https://github.com/gefrus112/Bytescript.git
cd Bytescript
make

You now have dist/bytescript, dist/libbytescript.so and dist/stdlib/ with the standard library modules (.so files).

Run the tests

make test

Put it on your PATH

mkdir -p ~/.local/bytescript
cp -r dist/* ~/.local/bytescript/
echo 'export PATH="$HOME/.local/bytescript:$PATH"' >> ~/.bashrc
# (use ~/.zshrc on zsh) then open a new terminal

Keep the folder contents together — bytescript loads libbytescript.so and stdlib/ from its own folder.

Check it works

bytescript --version
bytescript -e "print(2 + 3)"

Or download a build

Prebuilt Linux dist/ folders are attached to releases when available (and to every CI run under Actions → Build & test → Artifacts). Unpack, then do steps 4–5 above.

macOS

Build from source

Install the compiler tools

xcode-select --install

(That gives you gcc/clang, make and git. A GCC from Homebrew — brew install gcc — also works; the Makefiles call gcc.)

Clone and build

git clone https://github.com/gefrus112/Bytescript.git
cd Bytescript
make

This produces dist/bytescript with libbytescript.dylib and .dylib stdlib modules.

Run the tests

make test

Put it on your PATH

mkdir -p ~/.local/bytescript
cp -r dist/* ~/.local/bytescript/
echo 'export PATH="$HOME/.local/bytescript:$PATH"' >> ~/.zshrc

Open a new terminal afterwards. If Gatekeeper complains about an unsigned binary you downloaded, Right-click → Open once, or build from source (above) and it won't ask.

Check it works

bytescript --version
bytescript -e "print(2 + 3)"

Your first program

Create hello.bs

-- hello.bs
String who = "world"
print("Hello, " .. who .. "!")

for i = 1, 4 repeat
    print(i)
end

Run it

bytescript hello.bs
Hello, world!

Explore

Editor setup (optional)

For VS Code, copy the editors/vscode folder from the repository into your extensions folder and restart VS Code:

# Linux / macOS
cp -r editors/vscode ~/.vscode/extensions/bytescript-1.1.0

# Windows (PowerShell)
Copy-Item -Recurse editors\vscode "$env:USERPROFILE\.vscode\extensions\bytescript-1.1.0"

You get syntax highlighting, -- comments and end-aware indentation for .bs files.

Troubleshooting

ProblemFix
'bytescript' is not recognized / command not foundThe folder isn't on your PATH yet, or the terminal predates the change. Redo the PATH step and open a new terminal.
Windows: bytescript.dll was not found · Linux: libbytescript.so: cannot open shared object fileYou moved only the executable. Keep bytescript.exe/bytescript in the same folder as its library (the whole dist/ contents stay together).
Could not find file <…_map.bs> or stdlib imports failSame cause: the stdlib/ folder must sit next to the executable. Don't separate them.
make: command not foundInstall build tools (step 1 of your OS tab). On Windows use the MinGW 64-bit MSYS2 terminal and mingw32-make.
Build errors mentioning -march=nativeVery old/virtual CPUs only: build with make release instead of plain make.
macOS won't open a downloaded binaryRight-click → Open the first time, or build from source.
Still stuck?Open an issue with your OS, the exact command and the full error message.
