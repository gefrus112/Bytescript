Source code

Build it yourself — GCC + make, nothing else needed.

.zip .tar.gz

…or clone it:

git clone https://github.com/gefrus112/Bytescript.git

Build from source

git clone https://github.com/gefrus112/Bytescript.git
cd Bytescript
make          # or: mingw32-make   (Windows/MSYS2)
make test     # 24 checks, all should pass
./dist/bytescript --version

Then follow your OS tab in the install guide to put dist/ on your PATH. Build flavours: make (optimised, -march=native), make release (optimised, portable), make debug (symbols), make clean.

What you get

ContentsWhat it is
bytescript(.exe)The interpreter / REPL.
bytescript.dll + .lib / libbytescript.so / .dylibThe language as a library, for embedding in C programs.
bytescript.h, bytev.h, platform.hPublic C API headers.
stdlib/Standard library: Math, OS, Time, Random, Json, Base64, Debug + built-in module maps. Must stay next to the executable.
Source only: exemples/, tests/, docs/, website/, editors/Example programs, the test suite, documentation sources, this website, VS Code extension.

System requirements

Requirement
OSWindows 10+ (64-bit), any modern Linux (glibc, x86-64 — ARM builds from source), macOS 11+
To runNothing extra — the interpreter is self-contained.
To buildGCC (MinGW/MSYS2 on Windows) + GNU make. No other dependencies.
SizeA few hundred KB for the binaries.
